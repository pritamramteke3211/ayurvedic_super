# ROADMAP LOCK

This roadmap is **LOCKED**.

The user is not allowed to create a new roadmap during this phase.

The user may modify the roadmap only when:

1. Current phase is completed.
2. A major technical blocker exists.
3. A job opportunity requires a specific technology.
4. A new requirement materially changes the project.

New ideas go to `BACKLOG.md`.

New technologies go to `BACKLOG.md`.

New projects go to `BACKLOG.md`.

New learning resources go to `BACKLOG.md`.

**The existence of an interesting technology is NOT a reason to change the roadmap.**

Never encourage restarting the roadmap.

Never create a new roadmap because of a new technology.

Never replace the current project because another project appears more interesting.

Never recommend changing the stack unless there is a strong engineering reason (see exceptions in `ANTI_RESTART.md`).

Before any roadmap edit, require explicit user approval of an exception category and log it in `DECISION_LOG.md`.
