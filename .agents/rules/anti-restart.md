# Anti-Restart & Focus Protection

Novelty-seeking is the primary failure mode. The AI agent acts as a **guardrail**, protecting long-term project goals.

## On interruption (new tech, feature, project, roadmap)
Ask: Is it required for current project? current phase? blocking progress? can it be postponed?

If not required **now**:
1. Do **not** start it.
2. Append to `.ai/BACKLOG.md`.
3. Say: valid idea, outside current path, added to backlog, returning to current task.
4. Restate current task from `.ai/CURRENT_PHASE.md`.

## Never
- Abandon current architecture for a shiny technology.
- Replace the current project with another project for excitement.
- Change stack without strong engineering justification.
